2. FRAME 1 — B2 成員詳情頁（人版 vs 寵物版）
2.1 人成員版（左邊手機，標籤「👤 人成員版」）
由上到下結構：

頂欄：返回鍵 + 標題「成員詳情」 + 右上細掣「編輯資料」
身份區：
大圓形頭像 ~96px（綠色 1px 細 ring）
姓名 20px Bold：例如「陳大文 / 大仔」
關係標籤：18px，綠底米白字 pill：「仔」
相簿區：
區段標題「相簿」(18px Bold) + 配額標示 本月 相 3/5 · 片 1/2 16px muted
3 欄縮圖 grid（正方形 96–108px）；其中一張右上角有 8px #FF2800 紅點（白邊 2px），表示新內容
＋ 上傳相片／短片 按鈕：白底 + #228B22 邊框 + 綠色 18px Bold 文字；高度 ≥ 56px；pill 圓角 28px
「睇佢嘅動態」入口卡：標題 + 右側 chevron › icon + 受囑提示「去家庭圈，可以 like / 留言」
（若為 BB）「成長相簿」卡：綠色系 + 嫩芽 sprout icon + 文字「大仔嘅成長相簿」
底部 tab bar（家庭樹 active）
點擊頭像 / 按鈕：陰影增強表達可撳
2.2 寵物成員版（右邊手機，標籤「🐾 寵物成員版」）
由上到下結構：

頂欄：同上，標題「成員詳情」
身份區：
大圓形寵物頭像 ~96px，右上角 paw icon 🐾 12px badge
姓名 20px Bold：「Lucky」
關係標籤 18px 綠底米白字 pill：「大仔一家嘅狗仔」
主人標示：主人：陳大文、陳太 — 名字用綠色 underline 表示可點擊（跳去該人成員詳情），可一位或多位人成員
寵物生日：🐾 出生：2025年3月10日（突出顯示，避免與人類生日混淆）
相簿區：同人版完全一致（標題「相簿」+ 配額 + 3 欄 grid + 紅點）
＋ 上傳相片／短片 同 component
「成長相簿」入口卡：新寵物預設，文字「Lucky 嘅成長相簿」，icon 用 paw×leaf 組合
底部 tab bar
🚫 寵物版唔可以出現：自己發文、自己 like、自己留言、自己登入之類嘅「主人動作」元件 —— 寵物係被動成員。

2.3 兩版對比說明（顯示喺兩機底下細字 muted）
寵物版多咗「主人」「寵物生日」；少咗「睇佢嘅動態」入口，唔佔世代。

2.4 B2 互動規範（前端）
撳頭像 → 開大圖檢視
撳「編輯」→ 開編輯表（姓名 / 關係 / 出生日期 / 主人）
撳 ＋ 上傳相片／短片 → 系統相片選擇 → 上傳到該成員相簿（quota 內）

撳主人姓名 → 跳去該人成員 B2 頁

5. 無障礙 / 長者規範（全圖通用）
全部 body ≥ 18px，關係標籤 ≥ 18px。
點擊區 ≥ 44×44px；主 CTA ≥ 56px 高。
對比：主文字 vs 米白 ≥ 7:1；綠色 vs 米白 ≥ 4.5:1。
紅點永遠帶白邊 2px；唔可以純靠顏色區分狀態。
全部 icon 旁配文字。
觸控以單軸捲動為主。
文字語言：繁體中文（香港用語）；用 大新抱、大仔、阿女、孫仔、孫女、細仔、本人、太太、阿太 等本地稱謂；絕無簡體字。
memory 用 關係標籤 ≥ 18px 而非 16px，對應 senior-friendly 修正。

7. 互動細節（前端實作補充）
精靈 step 切換用前進 slide-from-right / 後退 slide-from-left 過場，時長 240ms ease-out。
Step indicator 進度點有 spring 動畫。
揀類型卡有 ripple press + 邊框由灰變 #228B22 高亮。
