4. 核心結構：Household Card + 分層 Carousel（本頁重點）
設計模型由 v1 嘅「單頭像樹狀圖」改為 「以小家庭（household）為單位、分層橫向 carousel」。

4.1 總覽
頁面分為由上而下嘅三代層（Generation Layers），層與層之間用 #228B22 連接線連住當前聚焦嘅卡。每一層可以係固定（pinned）或可橫撥（carousel）。

4.2 Generation 1（置頂，固定，唔可以橫撥）
一張 household 卡（白底、16px 圓角、柔和陰影、padding ≥ 20px，水平置中）。
卡內顯示「本人」「妻子」兩個同等大的圓形頭像並排（直徑 ~80px）。
兩者之間：`--color-accent`（#FF2800 法拉利紅）實心心形 icon（情感裝飾元素，詳見 rules.md 第 16 條色彩例外）。禁止粉紅色。
頭像下方：姓名 18px Bold + 關係標籤 16px Regular --text-muted（例如：本人、妻子）。
卡下方伸出一條 #228B22 垂直線（2px）向下連到 Generation 2 當前聚焦卡。
4.3 Generation 2（橫向 Carousel）
此層可能有多個小家庭：例如「長子一家」、「女兒一家」、「幼子一家」……

Layout：

一個橫向 scroll band（padding 左右 16px，overflow-x: auto，scroll-snap-type: x mandatory，隱藏 scrollbar）。
一次聚焦（focused）置中顯示 一張 household 卡，其餘左右只露一小截 + 淡化（opacity ≈ 0.5 + 輕微 scale 0.9 + grayscale 10%），暗示可左右 swipe 換房。
FOCUSED 卡（重點視覺）：

寬度約 280–320px（佔屏寬 ~80%）。
重點 • 邊框：2px solid #228B22 外框 + 較深陰影 + 輕微縱向抬高。
內部佈局：
如已婚：夫婦兩個頭像並排（同 Gen 1 大細或略小、~64px），中間 `--color-accent`（#FF2800）紅色實心心形 icon（情感裝飾，詳見 rules.md 第 16 條色彩例外）。
如未婚 / 單身：單一頭像置中。
如有寵物：寵物頭像（~48px）以 paw icon 🐾 在右上角 + 淺米色背景（與人成員區分），掛在主人（卡內最右）旁邊，標籤格式：[名字] · [主人的關係]的狗，例：Lucky · 長媳的狗。
頭像下：姓名 + 關係標籤（真實稱謂，例如「長子」、「長媳」、「女兒」、「孫兒」），禁用 placeholder。
半露卡（左右淡化截角）：

左右各顯示 1 張卡嘅一小截（露 ~32px 寬），提示「仲有更多」。
透明度 ~50%、微微縮小。
可在卡邊緣加極淡 chevron ‹ / › 作為 swipe 暗示。
房數指示點（Dots）：

顯示喺 focused 卡下方 16px。
格式：● ● ●（一共 N 個點，N = 該層家庭總數）。
當前聚焦：實心 #228B22；其他：--divider 外圈空心。
例：3 個家庭 → ● ○ ○（當前聚焦為「長子一家」）。
層間連接線：

從 Gen 2 focused 卡底部中央向下延伸 #228B22 2px 線 → 連到 Gen 3 focused 組。
4.4 Generation 3（橫向 Carousel，與 Gen 2 聯動）
聯動規則：Gen 3 只顯示 Gen 2 當前聚焦嗰家庭所生嘅仔女。Gen 2 swipe 去另一房，Gen 3 自動跳轉。
同樣橫向 carousel + 房數指示點（依該房仔女人數）。
例：Gen 2 focused = 「長子一家」→ Gen 3 顯示「孫兒」「孫女」兩個頭像（~64px），下標 孫兒、孫女。
若只有 1 個仔女 → 該層固定顯示，唔出指示點。
Gen 3 focused 卡同樣有 #228B22 邊框 + 比左右半露卡更強陰影。
4.5 層條件渲染規則
條件	該層行為
該層只有 1 個家庭	固定顯示，無 carousel，無指示點
該層有 ≥ 2 個家庭	橫向 carousel，顯示指示點
4.6 連接線全局規則
Gen 1 → Gen 2 focused 卡：垂直森林綠 2px 線。
Gen 2 focused 卡 → Gen 3 focused 卡：垂直森林綠 2px 線。
線條位置：每張卡底部正中央向下連，線長 ≈ 24px。
線條風格：straight solid line，2px 線寬，色彩 #228B22。
線條唔可以連到半露卡，只連 focused 卡（保持「對應關係」嘅視覺清晰）。

Focused 卡邊框 2px #228B22 同時可加 0 0 0 4px rgba(34,139,34,0.12) 擴散光環提升聚焦感。

結構差異：

唔顯示家庭切換下拉（單個家庭）。
主體改為單一頭像 + 鼓勵區 + CTA：
大圓形頭像（直徑 ~96px），下方標籤寫「本人」（唔可以寫「我」placeholder，亦唔可以出現任何 hex code / lorem ipsum）。

鼓勵文案（兩行，水平置中）：
第一行 22px Bold 開始建立您的家庭樹！
第二行 18px Regular --text-muted 加入您的家人，一同記錄成長。
CTA 按鈕（再下 24px gap）：
文字：+ 加入第一位家人
背景 #228B22
文字：白色 18px Bold Noto Sans TC
高度 ≥ 56px、padding ≥ 32px 水平
pill 圓角 28px

7. 互動行為（前端實作規格）
點擊頭像 → 進入「成員詳情頁 B2」。
點擊 top-right ＋新增家人 icon 或空狀態 CTA → 開啟「加入家人流程 B3」。
點擊 🔔 → 進入「通知中心 B5」。
點擊分享 → 觸發分享面板。
點擊 Gen 2 / Gen 3 carousel 任一卡 → 該層以 spring animation 將該卡置中並標為 focused。
Gen 2 focused 變化自動聯動 Gen 3（變化時 Gen 3 同步置中至對應一家的子女）。
點擊 indicator dot → 直接跳至該家庭。
左右 swipe 手勢 → 順利切換家庭（snap 行為）。
頂欄輔助圖示採純 icon（詳見 rules.md 第 16 條）；底部 Tab、CTA、表單按鈕等主流程元素全部必須 icon + 文字標籤並排（禁止 icon-only）。
8. 無障礙 / 長者優化 Checklist
點擊區全部 ≥ 44×44px；主 CTA ≥ 56px 高。
正文 ≥ 18px、關係標籤 ≥ 16px、鼓勵文案 22px。
色彩對比：主文字對米白 ≥ 7:1（AAA）、綠色對米白 ≥ 4.5:1（AA）。
紅點同時用白色外圈輔助，唔只靠顏色區分。
全部中文為繁體中文（書面繁中）：使用 長媳、長子、女兒、孫兒 等正式書面稱謂（詳見 memory_vault 稱謂對照表）；杜絕簡體字。
觸控手勢：單軸滾動為主（輪播只允許同時一個軸向），避開 multi-touch 衝突。
焦點狀態：所有可互動元素在鍵盤 / 輔助技術下都有清楚的 focus ring（建議 #228B22 outline 3px）。
9. 嚴格不做
❌ 任何付款 / 交易 / 金流 UI。
❌ 簡體中文字。
❌ 粉紅色（無論係配偶愛心、提示色、按鈕）。
❌ Icon-only 按鈕（必須 icon + 文字並排）。
❌ Large red surface（紅只限 8px 級別紅點）。
❌ Desktop 比例 / 寬螢幕 layout。
❌ 冷漠風格空狀態。
❌ Placeholder（User、#228B22、lorem ipsum 在 UI 畫面中）—— 模擬數據一律用真實稱謂。）
