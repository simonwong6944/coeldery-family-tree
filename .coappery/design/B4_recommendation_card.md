# B4 推薦卡設計規格 (B4_recommendation_card.md)

> 本檔為「家庭圈」(B4 feed) 內「推薦卡」之設計規格。
> 隸屬專案憲章 rules.md，如有衝突以 rules.md 為準。
> 登記日期:2026-08-31。任何修改須經產品負責人批准。

---

## 1. 定位與目的
- 推薦卡係插入「家庭圈」單欄 feed (方向 B) 之非家人動態卡片。
- 用途:向長者用戶展示與家庭相關之貼心建議 (例:預約家庭聚會、生日提醒延伸)。
- 核心原則:誠實標示為推薦，不得偽裝成家人貼文，不得硬銷 (rules.md 第 4 條)。
- 商業模式:第一版純展示，不涉金流 / 價格 / 商家 logo (rules.md 第 12 條)。

## 2. 語體 (rules.md 第 15.1 條)
- 推薦卡全部文字屬「系統文字」，一律正式書面繁體中文。
- 第二人稱一律用「您」。
- 禁用字依 rules.md 第 15.1 條清單，零命中。

## 3. 視覺方案 (方案 1:暖金底)
- 卡片背景:暖金 `#f3efe2` (淺、近米白，明顯區別於一般白色家人卡 `#ffffff` 及置頂綠色提醒卡)。
- 圓角:16px;柔和陰影 (同 design token `--shadow-soft`)。
- **識別色紅線**:
  - 不得使用森林綠 `#228B22` 作為推薦卡之識別背景色 (綠色專屬置頂提醒卡與主 CTA)。
  - 嚴禁橙色 `#F97316` (rules.md 第 1 條)，暖金底不得漂向橙色。
  - 禁止粉紅、禁止大面積紅色。
- 顏色一律以 CSS 變數定義，rgba 僅可寫於 `src/index.css`;禁止於組件內硬寫 hex。

## 4. 文案 (鎖定，不可更改)
| 元素 | 文案 | locale key (見 §7) |
| --- | --- | --- |
| 標籤 | 為您推薦 | b4_reco.label |
| 標題示例 1 | 為您推薦:預約家庭聚會 | b4_reco.title1 |
| 標題示例 2 | 下個月有幾位家人生日 | b4_reco.title2 |
| CTA 按鈕 | 了解更多 | b4_reco.cta |
| 關閉按鈕 | 稍後再提醒我 | b4_reco.dismiss |

## 5. 結構與長者友善規格 (rules.md 第 2 條)
- 由上而下:標籤 (為您推薦) → 標題 → 副標題 → 「了解更多」CTA → 「稍後再提醒我」關閉。
- 標籤:不得使用綠色作底;可用白底 + 淺邊框 + 暖灰褐字。
- 標題字級 ≥ 18px;副標題 ≥ 16px。
- 兩個按鈕:皆 icon + 文字或純文字，熱區 ≥ 44×44px;主 CTA 高 ≥ 56px。
- 禁止 icon-only 按鈕 (第 16 條例外不適用於此卡)。

## 6. 互動
- 點擊卡片本體或標籤:不導航 (避免長者誤觸)。
- 僅「了解更多」開啟內容 / modal。
- 「稍後再提醒我」:第一版僅視覺淡出 (fade-out only)，不呼叫任何 API。
- 淡出動畫:fade + slide-up 約 280ms (可依實作微調)。

## 7. locale key (待細步 A 落入 zh-Hant.json)
規劃新增區塊 `b4_reco`:
- b4_reco.label = "為您推薦"
- b4_reco.title1 = "為您推薦:預約家庭聚會"
- b4_reco.title2 = "下個月有幾位家人生日"
- b4_reco.cta = "了解更多"
- b4_reco.dismiss = "稍後再提醒我"

## 8. Out-of-Scope (第一版不做)
- dismiss API (POST /recommendation/{id}/dismiss)。
- 伺服器端出現頻率控制 (每日上限、用戶類別退訂)。
- 永久退訂某類推薦。
- A/B 測試框架。
- 任何付款 / 價格 / 商家品牌。
以上為將來 backlog，第一版僅做視覺淡出。
