# B4 家庭圈（Family Feed）UI 設計規格

## 核心原則
抄微信朋友圈個骨、WhatsApp 嘅親切、減到只剩核心。一眼睇明,唔使學。長者友善優先。

## 一、頁面結構（由上到下）
1. 頂欄：現有 top-bar,標題「家庭圈」。不加封面相、不加自己頭像。
2. Feed：一則則動態,由上到下 scroll。
3. 底欄：現有 bottom-tab-bar,「家庭圈」active。

## 二、一則動態（post card）
1. 頂部：發文人頭像（圓形 ~48px）+ 名（粗體）+ 時間（灰,例「2 小時前」）。
2. 「關於邊個」標籤：細 pill,例「關於：長子」。mockup 階段撳無動作,日後 filter 該人動態。此為老有卡對比 FB/微信之差異化核心價值,保留。
3. 相片：一張大相（滿卡闊度）；多張時用 grid。相要大。
4. 短文字說明：≥18px。
5. 分隔線。
6. 互動列：
   - 讚好掣：寫住字「❤️ 讚好」,撳咗變實心紅。不用 double-tap 手勢。
   - 留言掣：寫住字「💬 留言」。
   - 讚好顯示：用名不用數字,例「陳大文、陳美玲 讚好」。（註：真做階段人多時或改為「陳大文等 N 人讚好」,mockup 階段用名。）

## 三、留言顯示
mockup 展示已有留言（頭像 + 名 + 短文字）。

## 四、發新動態掣
底部右下角浮動綠色圓掣「＋」。撳咗 mockup 階段無動作。選浮掣因夠大夠明顯,長者易撳。

## 五、假動態內容（3 則,用家人真名）
1. 陳美玲 · 2 小時前 · 關於：Lucky · 相（dog.ceo）·「今日帶 Lucky 去公園散步 🐾」· 陳大文 讚好 · 陳大文留言「好得意！」
2. 陳志明 · 今日 · 關於：陳嘉俊 · 相（randomuser）·「阿仔今日考試攞咗 A 🎉」· 陳大文、陳美玲 讚好
3. 陳大文 · 昨日 · 關於：本人 · 相（randomuser）·「一家人飲茶,好開心」· 陳美玲 讚好 · 陳志明留言「下次一齊去！」

## 六、長者友善（跟 rules §5 / 設計通則）
字 ≥18px、相大、掣熱區 ≥44px、所有 icon 配文字、色用 src/index.css CSS 變數、綠色主調、禁 hard-code hex、禁簡體、禁粉紅/orange。

## 七、mockup 範圍（靜態）
所有互動（讚好、留言、發布、filter 標籤）撳咗無實際動作,純展示版面。真功能留後端階段。
